# Tarea Corta #1 - Coloración de Grafos
### Descripción
Se implementa un Algoritmo Genetico para el problema de coloracion de grafos, dado un grafo no dirigido y un numero fijo de colores k, se busca asignar un color a cada vertice de manera que se minimice el numero de aristas cuyos dos extremos comparten el mismo color.
